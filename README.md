DESCRIPTION:
A Waveshare ESP32-S3-1.47" LCD Dev Board based PWNagotchi-esque build.

Using a cheap Waveshare ESP32-S3-1.47" LCD Dev Board and a Random USB-A to USB-C addapter, this Repo will help you make a very small, PWNagotchi styled device.

This device does not collect handshakes. This device is purely a PASSIVE system. this is to ensure it stays within any legal or regulatory requirements in as large of a demographic as possible.

With this Device, you will be able to "Sniff" WiFi and BLE broadcasts, and create an internal log containing the Header details for recording and to avoid the device becoming "fixated" on one network at a time"

"Rare" MAC addresses will grant the device "Gem Stones", and all discoveries will grant your device EXP and Stat leveling.
